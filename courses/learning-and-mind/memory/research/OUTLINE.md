# Outline: Memory

*Stage 2, 2026-09-19. Written from `research/SOURCES.md` and from `npm run taught
courses/learning-and-mind/memory`, which lists 111 lessons across eleven written courses that a
learner reaching this point has already had.*

## How many lessons, and why

**Seven.** The same count as the two courses before it in this term, and for a reason that is
specific to this one: **this course has five literatures and each needs a lesson**, plus an opening
that draws the boundary and a close that outlives the figures.

**The count is set by what the evidence can carry, not by the size of the subject.** Memory is an
enormous field and this course reads five things in it properly. A course that tried to survey it
would be a textbook summary written from search results, which is the failure mode this institute
was built against.

**What the seven are.**

1. What memory is not, and what this course is for
2. What forgetting looks like when somebody plots it
3. What retrieving one thing does to its neighbours
4. What a question does to a memory
5. What a confident memory is worth
6. What the techniques do
7. Reading a claim about your memory

## Six decisions, settled here so no lesson re-opens them

**Decision 1. The boundary with How to Learn Anything is drawn in lesson 1 and held.** That course
teaches retrieval practice, spacing, interleaving, chunking, working memory and the two strengths.
**This course uses all of them and re-teaches none.** Where a lesson needs one it points, in the
form Focus lesson 2 used for Time Management lesson 5. Lesson 3 is the bridge and is the only place
the two courses genuinely meet.

**Decision 2. Every figure carries what it was measured on and when, in the body, at each
appearance.** This course's samples are the smallest in the institute: one subject in lesson 2, a
hundred and fifty undergraduates in lesson 4, fifty people in lesson 6. **Lesson 1 names the gap
once as a section, and each lesson restates the scope where its own figure appears.**

**Decision 3. Lesson 4's provenance is the course's own worked case, deliberately.** The Loftus and
Palmer figures come from a published teaching summary because the original could not be opened.
**The lesson says so at the point of use and makes it the teaching point**, the way Habits lesson 4
made Maltz's provenance its own. A lesson that hid it would be worse than one that did not use the
study.

**Decision 4. The unverified meta-analysis figure never appears.** `SOURCES.md` records it as a gap
precisely so that a drafter meets the gap. **If a later session finds the paper, it goes into
`SOURCES.md` first and a lesson second.**

**Decision 5. Lesson 5 is written with the care of a lesson that could be quoted at somebody.**
Eyewitness identification is about convictions. `sensitive_domain` is `false` and standards 3.4's
list does not reach it, and the lesson still carries the synthesis's own qualifications in full:
adults, initial identifications, five named conditions, and jurisdictions that have not adopted the
reforms. **The single word "initial" is load-bearing and appears wherever the claim does.**

**Decision 6. No lesson tells a reader that their own memory is unreliable in a way that should
change what they do about a particular remembered event.** The course teaches what has been
measured about memory in general. **It is not a tool for adjudicating anybody's recollection**, and
lesson 7 says so in terms. This is the course's main refusal and it is sharper than the two before
it, because a reader could otherwise take lesson 4 and use it on somebody.

## Lesson 1. What memory is not, and what this course is for

**Objectives.**

- State the difference between a recording model of memory and a reconstructive one, and say what
  each predicts
- Say what this course promises and what it refuses to promise, and identify a claim about memory
  that the course could not support
- Name the population and the sample size behind each of this course's main sources, and say what
  that licenses

**Core ideas.** The recording metaphor, and the fact that every finding in this course is downstream
of it being false. **The point is not that memory is bad**, which is the version a reader will
arrive with. It is that reconstruction is what memory does, and that the ways it goes wrong are
therefore systematic and measurable rather than random.

**Mechanism to explain.** What "reconstructive" means concretely: that retrieving is an act that
changes what is stored, which is why lessons 3 and 4 are possible at all.

**Worked examples.** (a) One remembered event, described twice, with the differences a
reconstructive account predicts and a recording account does not. **Constructed and labelled.**
(b) The scope table for this course's five sources: what each measured, on whom, how many, when.
**This is real and it is the section decision 2 exists for.**

**Misconceptions.** "Memory is a recording." "Reconstruction means memory is unreliable" — which
over-corrects. "A vivid memory is a reliable one."

**Practice.** (1) Write down one memory in as much detail as you can, date it, and put it away; the
project comes back to it. (2) Take one claim about memory you have met and write down which of the
five sources' kinds of evidence would have had to produce it.

**Sources.** All five, for the scope table. **Connections.** Back to **How to Learn Anything** for
the boundary, and to **Focus and Deep Work** lesson 1 for the instrument question, which this course
assumes. Forward to every lesson.

## Lesson 2. What forgetting looks like when somebody plots it

**Objectives.**

- State what the method of savings measures and how it differs from a percentage recalled
- State what the 2015 replication found, with its sample and its intervals
- Explain what the jump at 24 hours is and why it matters that the curve is not smooth

**Core ideas.** The forgetting curve is the founding figure of the subject and is reported
everywhere without its scope. **One subject. Seventy hours. Nonsense syllables. Relearning intervals
of twenty minutes, one hour, nine hours, one day, two days and thirty-one days.**

**Mechanism to explain.** Savings. Why measuring the time saved on relearning is a different
instrument from asking how much somebody remembers, and what each is good for. **Focus lesson 1's
instrument question, applied to a measure from the 1880s.**

**Worked examples.** (a) The same material measured both ways, so the reader can see the two
instruments disagree. **Constructed.** (b) The replication's own conclusion that the curve is not
smooth, and what a jump at 24 hours would mean if it is real. **The wrinkle**: the lesson has to say
that this course has not read the curve fits, so it reports the authors' conclusion rather than
weighing it.

**Misconceptions.** "You forget half of what you learn within an hour." "The curve is a law."
"A replication means the original was right about everything."

**Practice.** (1) Run a savings measurement on yourself with a small set of arbitrary items, twice,
a week apart. (2) Find the forgetting curve in the wild and write down what is missing from how it
is presented.

**Sources.** 1. **Connections.** Back to lesson 1 and to **How to Learn Anything** lesson 4, which
is spacing and which this lesson explains the shape behind. Forward to lesson 3, which is why the
curve looks the way it does.

## Lesson 3. What retrieving one thing does to its neighbours

**Objectives.**

- State what retrieval-induced forgetting is and what the meta-analysis found, with its intervals
- Explain why the pooled figure differs by a factor of two depending on one methodological choice
- Reconcile this finding with retrieval practice, which the earlier course recommends

**Core ideas.** Retrieving a subset of items can cause the forgetting of other items. **The
meta-analysis gives three numbers and the lesson is in the gap between them**: about nine percent
overall, eleven when output interference is not controlled, five when it is.

**Mechanism to explain.** Two accounts, in the authors' own words: inhibition, and non-inhibitory
competition or blocking. **The lesson states both and declines to settle**, because the
meta-analysts do: their results "largely supported inhibition accounts, but also provided some
challenging evidence".

**Worked examples.** (a) The three raw figures read side by side, with what output interference is
and why controlling for it halves the number. (b) A reader who has been doing retrieval practice
since **How to Learn Anything** lesson 3, and what this finding does and does not mean for them.
**The wrinkle**: it does not mean stop, and the lesson has to say what it does mean without
inventing a practical recommendation nothing supports.

**Misconceptions.** "Testing yourself damages your memory." "A pooled number is the effect."
"Inhibition has been proved."

**Practice.** (1) Take a set of things you know in categories and notice which ones you reach first
and which get harder. (2) Read the three figures and write one sentence on what a single-number
report of this effect would hide.

**Sources.** 2. **Connections.** Back to **How to Learn Anything** lesson 3, which this lesson is in
tension with and does not contradict, and to **Focus and Deep Work** lesson 4, which is where a
pooled figure splitting by method was first taught. Forward to lesson 4.

## Lesson 4. What a question does to a memory

**Objectives.**

- State what the 1974 experiments did and found, and at what read level this course holds them
- Distinguish a response-bias account from a memory-change account, and say what would separate them
- Trace a famous study to its source and say what you could and could not establish

**Core ideas.** The verb changes the estimate; a week later, the verb changes what people say they
saw. **The broken glass is the finding**, and it is sixteen people against seven against six.

**Mechanism to explain.** The two interpretations the authors themselves give, and what evidence
would tell them apart.

**Worked examples.** (a) The two experiments laid out with their figures and their scope. (b) **The
provenance trace, which is decision 3 and the lesson's real subject.** This course could not open
the original. It read a published teaching summary from an examination board. The lesson walks that
trail, says exactly what it establishes, and names the five endings a trace can have, which Habits
lesson 7 and Focus lesson 7 both use.

**Misconceptions.** "Leading questions implant memories." "The study proves memory is unreliable."
"A small study with a famous result is a strong study."

**Practice.** (1) Trace one famous study in twenty minutes. (2) Write two versions of a question
about something you witnessed this week, one neutral and one leading, and say what each would be
likely to produce.

**Sources.** 3. **Connections.** Back to lesson 1's reconstructive account, which this is the
demonstration of. Forward to lesson 5, which is what happens when the stakes are real.

## Lesson 5. What a confident memory is worth

**Objectives.**

- State what the traditional position on eyewitness confidence was and why it was reasonable
- State the five pristine conditions and what follows from them, in the synthesis's own terms
- Explain why "initial" is the load-bearing word in the whole claim

**Core ideas.** The course's best lesson. Everybody knows confidence is worthless; the synthesis
opens by saying that was entirely reasonable for the procedures that produced it. **Under five named
conditions, initial high confidence is remarkably accurate and initial low confidence signals a high
risk of error.**

**Mechanism to explain.** What each of the five conditions is protecting against, one at a time, and
why a confidence statement taken later is a different measurement from one taken at the moment.

**Worked examples.** (a) Box 3 worked condition by condition. (b) The field-study figures: 96
percent of 72 high-confidence identifications correct, and a model estimating 97 percent against
about 50 for low confidence. **The wrinkle**: the same evidence supports exonerating the innocent
and convicting the guilty, and the lesson has to hold both rather than picking the comfortable one.

**Misconceptions.** "Confidence means nothing." "This proves eyewitnesses are reliable." "A
confident witness in court is a confident witness."

**Practice.** (1) Take a lineup procedure described in a news story and check it against the five.
(2) Write the strongest case for the traditional position and then the strongest case against, from
the synthesis's own words.

**Sources.** 4. **Connections.** Back to lesson 4. From earlier courses, **Logic and Argument**
lesson 6 for what a conditional claim is. Forward to lesson 7.

## Lesson 6. What the techniques do

**Objectives.**

- Describe the method of loci and what the training studies measured
- Apply the transfer distinction to a memory technique, and say which level its evidence reaches
- Say what this course can and cannot tell somebody who wants a better memory

**Core ideas.** A six-week training study with three arms, one of which is an active control, and a
retest at four months. **The design is better than most in this area and the lesson should say
why**, which is Focus lesson 6's point arriving in a different literature.

**Mechanism to explain.** Transfer, imported from Focus lesson 6 rather than re-taught. The method
of loci works on ordered lists of arbitrary items; whether it does anything for the material a
learner wants is the transfer question and this course has not read the answer.

**Worked examples.** (a) The technique demonstrated on a short list, so the reader has done it. (b)
A claim about a memory course, sorted by transfer level. **The wrinkle**: the honest answer for the
method of loci is better than for brain training and is still not what the advertising says.

**Misconceptions.** "Memory athletes have better memories." "A technique that works on lists works
on everything." "Mnemonics are a trick rather than a skill."

**Practice.** (1) Build one memory palace and use it on a real list. (2) Sort a memory product's
claim by transfer level.

**Sources.** 5, and **Focus and Deep Work** lesson 6 for transfer. **Connections.** Back to lesson
3, because the technique is a way of managing interference. Forward to lesson 7.

## Lesson 7. Reading a claim about your memory

**Objectives.**

- Sort a claim about memory into measurable, unmeasurable as stated, or false, and say what would
  settle it
- Identify what a memory claim was measured on, and say what a small or specific sample licenses
- Decide what to do about one remembered event of your own, with what each option costs

**Core ideas.** The lesson that carries everything perishable. **Its own move is the sample
question**, which is this course's addition to the institute's standing sort: this subject's
evidence is built on the smallest samples in the institute, and the claims built on it are the
largest.

Then the five sources side by side with what each rests on, so the pattern is visible.

Then the trade books, named as widely read and cited for nothing.

Then decision 6's refusal, faced: **this course cannot tell you whether a particular thing you
remember happened.** What it can tell you is what memory does in general, which is a different
question, and the difference is the last thing the course teaches.

**Worked examples.** (a) Four claims sorted, one of each kind plus one that is two claims stuck
together, each worked rather than asserted. (b) The five-source table.

**Misconceptions.** "Somebody must have checked." "The science says." "A famous study is a big
study."

**Practice.** (1) Trace one claim about memory in twenty minutes, with the five endings. (2) **The
decision**: take the memory you wrote down in lesson 1, read it again, and decide what to do with
it. Three endings, all worked: treat it as it stands, treat it as an account you cannot check, or
find out whether anything external corroborates it. **All three must be worked**, per the neutrality
note below.

**Sources.** All. **Connections.** Back to the whole course. Out to **Note-Taking and Personal
Knowledge**, which is the next course in this term and is unwritten.

## Assessments

### Course-end test

**Eighteen items.** At least thirteen must be application to material in no lesson.

| Area | Items | Kind |
|---|---|---|
| Reconstruction, and what this course is for (L1) | 3 | 1 recall, 2 application |
| The forgetting curve and the method of savings (L2) | 3 | 1 recall with scope, 2 application |
| Retrieval-induced forgetting (L3) | 3 | all application |
| What a question does, and its provenance (L4) | 3 | 1 recall with read level, 2 application |
| Confidence and accuracy (L5) | 3 | all application |
| Techniques and transfer (L6) | 2 | both application |
| Sorting a claim (L7) | 1 | the sorting item |

**Three items must be cross-lesson**: one pairing lesson 3's finding with **How to Learn Anything**'s
retrieval practice, because a learner will think they conflict; one pairing lesson 2's instrument
with lesson 5's, because both turn on when the measurement was taken; and one pairing lesson 4's
provenance with lesson 7's sorting.

### Project: one memory, traced

**Deliverable.** One plain text or Markdown file, roughly 1,000 to 1,800 words, in four sections.

**Budget about five hours**, spread across the course rather than at the end.

**The design problem this solves.** No section can have a key, because the answer is the learner's
own memory. **So every section asks for a record, then a check, then the gap.**

**Steps.** (1) Written in lesson 1 and not edited afterwards: one remembered event, in as much
detail as the learner can give, dated. (2) A second account, written from memory at the end of the
course, without looking at the first. (3) The comparison: what differs, what is more detailed the
second time, and what a reconstructive account predicts about each difference. (4) The decision from
lesson 7, with what it costs.

**Rubric.**

| Criterion | What full marks look like |
|---|---|
| The first account is untouched | Section 1 is dated and demonstrably not edited after lesson 1 |
| The second account is independent | Written without re-reading the first, and the learner says so |
| The comparison is specific | Differences are named item by item rather than summarised |
| The reconstructive account is applied, not asserted | Section 3 says which differences the account predicts and which it does not |
| Scope is respected | No figure from the course is quoted without what it was measured on |
| The decision names its cost | Section 4's decision has something on the other side of it |

**A learner whose two accounts match closely has not failed the project.** Nothing in this course
predicts how much any particular memory will change, and a rubric that scored only divergence would
be teaching a result the evidence does not support.

## Neutrality notes

`sensitive_domain: false`, and the call is worth stating: standards 3.4's list does not reach this
subject. Three things still need care.

- **Lesson 5 could be quoted at somebody.** It is about convictions. Every qualification the
  synthesis makes travels with every claim the lesson makes, and the word "initial" appears wherever
  the claim does.
- **Lesson 7's decision is standards 3.1 case 3**, and all three endings must be worked, which is
  the note Habits 7 and Focus 7 both passed.
- **Decision 6 is a refusal a reader will push on**, harder than the refusals in the two courses
  before this one, because somebody will want to use lesson 4 on a person. The lesson has to decline
  without implying the reader's memory is worthless, which is a harder sentence than it looks.

## What is deliberately left out

- **Memory and ageing.** Not searched, a different literature, and real distress available if a
  general course touches it lightly. Named in lesson 1 as something the course is not doing.
- **Clinical memory disorders.** Different literature, different question.
- **Recovered and repressed memory.** The most contested question in the whole subject, and this
  course has read none of it. **If a later session researches it properly, it is an eighth lesson**,
  and it would need the standards' contested-question handling in full.
- **The neuroscience.** Real, not read, and a lesson of diagrams would be decoration.

## What downstream courses will need this one to have taught

**Note-Taking and Personal Knowledge** (T2, unwritten) will need the reconstructive account, because
the whole case for writing things down rests on it. Nothing else on the map depends on this course.
