# Reviews: Note-Taking and Personal Knowledge

One file per lesson, plus `course-wide.md` for findings that belong to the course rather than to a
lesson. Each file records what a Stage 4 review returned, what was clean, and what was applied.

Reviews are run Tier A, one subagent in a fresh context, all six passes. `sensitive_domain: false`,
and the neutrality pass is run anyway: psychology is on standards 3.4's list, this course's lesson 6
is a live disagreement between two open-access papers, and its lesson 7 has to decline to give a
verdict on a practice many readers already use.
