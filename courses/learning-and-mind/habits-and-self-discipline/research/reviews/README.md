# Reviews: Habits and Self-Discipline

One file per lesson, plus `course-wide.md` for findings that belong to the course rather than to a
lesson. Each file records what a Stage 4 review returned, what was clean, and what was applied.

**These files are the record, not the work.** The fixes live in the lessons and in the commits named
at the end of each file. What a review file is for is the next course: the same defects recur, and
the only way anybody knows which ones is that somebody wrote them down here and then into
`.claude/commands/draft-lesson.md`.

Reviews were run Tier A, one subagent in a fresh context per batch, all six passes: depth,
fact-check, neutrality, pedagogy, cold start, voice and media. `sensitive_domain: false` and no
standpoint, so one reviewer is the standard this repo sets for this kind of course.
