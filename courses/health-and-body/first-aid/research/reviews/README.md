# Stage 4 reviews, First Aid and CPR

One file per lesson. Each lesson is a sensitive-domain lesson, so it gets two fresh-context
reviewers (F: facts, neutrality and safety; P: depth, pedagogy, cold start, voice and media) and a
third context for the fixes. Their findings files are folded into the lesson's single record here,
with a "Resolutions applied" section. `course-wide.md` holds the neutrality audit and anything that
applies across lessons.
