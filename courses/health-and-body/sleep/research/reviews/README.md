# Stage 4 review records: Sleep

One file per lesson, named for the lesson, plus `course-wide.md` for findings that belong to the
course rather than to any one lesson. Each file records the review as it came back, what was applied,
and what was not applied and why.

**This course is a sensitive domain under standards 3.4** (medicine), so the neutrality pass is
mandatory on every lesson and the neutrality audit is mandatory before publish. The specific risk
here is not political: it is a health course drifting into telling a reader what to do about a body
it has never examined.
