# Stage 4 review records: Cooking Fundamentals

One file per lesson, plus `course-wide.md` when a finding belongs to no single lesson. Not a
sensitive domain under standards 3.4 and not a standpoint course, so every lesson is reviewed Tier A:
one fresh-context reviewer doing every applicable pass, then the fix pass. Lesson 4 (food safety) is
the one to watch: if its review finds wrong facts, it escalates to Tier B. Each lesson is drafted in
one context and reviewed in another, so no context that wrote a sentence is the one that judges it.
